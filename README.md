# XR Accessibility Prototype
This Unity Project is a prototype XR accessibility tool designed for desktop playback. It demonstrates accessibility features such as real-time captioning with Azure Speech-to-Text, speaker isolation, custom naming for speaker identification, and customizable UI for speech readability.
Note: Azure region and keys are intentionally left in the project for demonstrator viewing.

Watch the Demo! (https://github.com/gracenbarnhart/XR_AccessibilityPrototype-Demo/raw/main/DemonstrationVideo.mp4) 
Click “Raw File” in your browser to download the video if it starts playing instead.)

Requirements: 
Unity Version 6000.1.6f1 (Unity 6)
Platform Target: Desktop (Windows)
Scene to Load: "TestScene"

Opening the Project:
Clone the repo:
gh repo clone <gracenbarnhart/XR_AccessibilityPrototype-Demo>
Or click Code, Download ZIP on Github page, then extract it.
Click Add and select the project folder you just cloned.
Ensure the Unity version is set to 6000.1.6f1.

Running the Project:
In Unity, open Assets/TestScene.unity
Press PLAY in the editor.
Toggle the scale setting to see full heads-up display.
The project will run in desktop mode.

Azure Configuration:
This prototype uses Azure Speech Services
The credentials and region are no longer embedded- setup is required for playback.

Notes:
Designed for desktop viewing, no VR headset required.
For VR playback, adjust the XR settings in Project Settings, XR Plug-in Management.
